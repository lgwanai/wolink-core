# WoLink Core 产品白皮书

## 企业级 AI 网关解决方案

---

## 执行摘要

WoLink Core 是一款面向企业的 AI 模型统一接入与治理平台，帮助企业安全、高效、可控地使用大语言模型（LLM）。通过统一的 API 接口、细粒度的权限控制、全面的审计日志和成本管控能力，WoLink Core 让企业能够放心地将 AI 能力融入业务流程，同时满足合规与安全要求。

---

## 一、企业 AI 应用面临的挑战

### 1.1 多模型管理的复杂性

- **供应商分散**：OpenAI、Azure、Claude、DeepSeek 等多家供应商，API 规范各异
- **接入成本高**：每个业务系统需要单独对接，重复开发，维护困难
- **切换代价大**：更换模型供应商需要修改业务代码，风险高

### 1.2 安全与合规风险

- **数据泄露**：敏感信息通过 Prompt 发送给外部 AI 供应商
- **缺乏审计**：AI 调用记录分散，难以追溯和审计
- **权限失控**：谁在什么时候调用了什么模型，调用结果如何，缺乏管控

### 1.3 成本难以控制

- **用量不透明**：各部门、各项目的 AI 调用成本无法清晰统计
- **预算失控**：Token 消耗无上限，月度账单难以预测
- **资源浪费**：重复调用、无效调用无法识别和优化

## 二、WoLink Core 解决方案

### 2.1 产品定位

WoLink Core 定位为企业 AI 基础设施层，作为企业与 AI 供应商之间的统一网关：

```
┌─────────────────────────────────────────────────────────────┐
│                      企业业务系统                            │
│    (CRM / ERP / OA / 客服 / 数据分析 / 内部工具)            │
└─────────────────────────────────────────────────────────────┘
                              │
                              ▼
┌─────────────────────────────────────────────────────────────┐
│                     WoLink Core                             │
│  ┌─────────┐ ┌─────────┐ ┌─────────┐ ┌─────────┐          │
│  │统一接入 │ │权限管控 │ │安全审计 │ │成本治理 │          │
│  └─────────┘ └─────────┘ └─────────┘ └─────────┘          │
└─────────────────────────────────────────────────────────────┘
                              │
                              ▼
┌─────────────────────────────────────────────────────────────┐
│              AI 模型供应商 (OpenAI / Claude / DeepSeek...)  │
└─────────────────────────────────────────────────────────────┘
```

### 2.2 核心能力

#### 统一接入层

| 特性 | 说明 |
|------|------|
| **OpenAI 兼容协议** | 无需修改现有代码，标准 OpenAI API 格式 |
| **多供应商支持** | 支持 OpenAI、Azure OpenAI、Claude、DeepSeek 等 |
| **智能路由** | 根据模型可用性、成本、性能自动选择最优路径 |
| **流式响应** | 支持 SSE 流式输出，低延迟用户体验 |

#### 安全治理层

| 特性 | 说明 |
|------|------|
| **敏感信息检测** | 自动识别身份证、手机号、银行卡等敏感数据 |
| **数据脱敏** | 敏感信息自动替换为占位符，保护隐私 |
| **部门隔离** | 按部门分配 API Key，资源独立管理 |
| **权限分级** | 普通管理员 / 超级管理员角色分离 |

#### 审计合规层

| 特性 | 说明 |
|------|------|
| **全量日志** | 记录每次 AI 调用的请求、响应、Token 消耗 |
| **会话追溯** | 完整保存对话上下文，支持事后审计 |
| **操作审计** | 管理员操作记录，满足内控要求 |
| **导出报表** | 支持按时间、部门、项目导出审计数据 |

#### 成本管控层

| 特性 | 说明 |
|------|------|
| **配额管理** | 按部门设置日限额、月限额，超限自动拒绝 |
| **并发控制** | 限制同时进行的请求数，防止资源滥用 |
| **用量统计** | 实时展示各部门 Token 消耗趋势 |
| **成本预警** | 接近预算阈值时自动告警 |

## 四、部署方案

### 4.1 私有化部署 (推荐)

适用于对数据安全有严格要求的企业：

```
┌─────────────────────────────────────────┐
│           企业内网 / 私有云              │
│  ┌─────────────────────────────────────┐│
│  │  WoLink Core                        ││
│  │  ├─ API Gateway (端口 8080)         ││
│  │  ├─ 管理后台 (端口 8080)            ││
│  │  └─ Prometheus 指标 (端口 9090)     ││
│  └─────────────────────────────────────┘│
│  ┌─────────────────────────────────────┐│
│  │  数据层                              ││
│  │  ├─ PostgreSQL (审计日志/配置)      ││
│  │  └─ Redis (缓存/限流)               ││
│  └─────────────────────────────────────┘│
└─────────────────────────────────────────┘
```

**优势**：
- 数据完全在企业内网，满足安全合规要求
- 可对接企业现有认证系统 (LDAP / AD / SSO)
- 支持定制化开发

### 4.2 混合云部署

```
┌───────────────────────────────────────────────────────────┐
│                        混合云架构                          │
├───────────────────────────────────────────────────────────┤
│                                                           │
│   企业内网                      公有云                    │
│  ┌─────────────┐              ┌─────────────┐            │
│  │ 业务系统    │◄────────────►│ WoLink Core │            │
│  │ (敏感数据)  │   VPN/专线   │ (API 网关)  │            │
│  └─────────────┘              └─────────────┘            │
│                                      │                    │
│                                      ▼                    │
│                               ┌─────────────┐            │
│                               │ AI 供应商   │            │
│                               │ (OpenAI...) │            │
│                               └─────────────┘            │
└───────────────────────────────────────────────────────────┘
```

### 4.3 快速开始

```bash
# Docker 部署
docker run -d \
  --name wolink-core \
  -p 8080:8080 \
  -e DATABASE_URL=postgres://user:pass@host:5432/wolink \
  -e REDIS_URL=redis://host:6379 \
  wolink/core:latest

# 健康检查
curl http://localhost:8080/health
# {"status":"ok"}
```

- 启用敏感信息脱敏

**效果**：
- 接入效率提升 80%，1 天完成统一接入
- 成本透明化，按业务线精确分摊
- 零敏感数据泄露事件

**方案**：
