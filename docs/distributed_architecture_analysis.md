```yaml

  enabled: true
  mode: "local"               # local / shared / disabled
```

### 📈 性能考虑

#### 连接池配置

**数据库连接池：**
```
总连接数 = 节点数 × max_open_conns

示例（3节点）：
- 每节点：50连接
- 总共：150连接
```

**Redis连接池：**
```
总连接数 = 节点数 × pool_size

示例（3节点）：
- 每节点：50连接
- 总共：150连接
```

#### 日志写入性能

- **本地写入**：无性能影响（异步批量）
- **Redis同步**：异步非阻塞，延迟 < 1ms
- **基准测试**：78.26 ns/op（极低开销）

### 🔐 数据一致性保证

| 数据类型 | 一致性模型 | 说明 |
|---------|-----------|------|
| API Key | 强一致 | Redis缓存 + 数据库 |
| 速率限制 | 强一致 | Redis原子操作 |
| 对话记录 | 最终一致 | 队列异步写入 |
| 使用日志 | 最终一致 | 队列异步写入 |

### 🎯 部署建议

#### 小规模部署（< 1000 QPS）
```yaml
节点数：2-3
数据库：单主实例
Redis：单实例或Sentinel
连接池：25-50/节点
```

#### 中规模部署（1000-5000 QPS）
```yaml
节点数：3-5
数据库：主从复制
Redis：Sentinel模式
连接池：50-100/节点
负载均衡：Nginx/ALB
```

#### 大规模部署（> 5000 QPS）
```yaml
节点数：5+
数据库：主从 + 读写分离
Redis：Cluster模式
连接池：100+/节点
负载均衡：L4/L7负载均衡器
日志收集：ELK/EFK Stack
```

### ⚠️ 注意事项

1. **模型配置文件**
   - 当前每个节点需要本地配置文件
   - 建议使用共享存储或配置中心
   - 未来可考虑数据库化存储

2. **会话保持**
   - 如果有WebSocket连接，需要会话保持
   - 或使用Redis存储会话状态

3. **日志管理**
   - 本地日志需要定期归档
   - 建议开启Redis同步集中收集
   - 使用日志轮转工具（logrotate）

4. **监控告警**
   - 监控各节点健康状态
   - 监控数据库连接池使用率
   - 监控Redis内存和连接数
   - 监控队列长度和延迟

5. **安全加固**
   - 节点间通信使用内网
   - 数据库和Redis启用认证
   - 使用TLS加密传输
   - 定期更新密码

### 🔄 扩缩容

#### 水平扩展（增加节点）
1. 启动新节点（相同配置）
2. 添加到负载均衡器
3. 自动开始处理请求
4. **无需重启现有节点**

#### 水平收缩（减少节点）
1. 从负载均衡器移除节点
2. 等待现有请求完成
3. 停止节点服务
4. **不影响其他节点**
