## 设计偏好

1. 该项目作为纯粹的网关存在，不用存储用户任何信息
2. 支持单节点和多节点模式配置，单节点，以配置文件为准，所有的模型、apikey都使用配置文件配置
3. 多节点模式，通过配置的token和master节点ip，通过api拉取 apikey白名单，模型配置等信息

## 架构方向

- 网关完全无状态，不存储任何用户数据
- 去数据库连接（MySQL/PostgreSQL）
- 单节点模式：从配置文件读取所有配置（模型、API Key）
- 多节点模式：从 admin 管理端通过 API 拉取配置同步到本地
- API Key 白名单本地缓存，定时同步
- 模型配置本地缓存，定时同步
