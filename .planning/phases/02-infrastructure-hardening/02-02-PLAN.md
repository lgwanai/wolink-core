<objective>
Create separate `/health` (liveness) and `/ready` (readiness) endpoints for Kubernetes probes. The health endpoint only checks if the server is running, while the readiness endpoint checks database and Redis connectivity.

Purpose: Enable Kubernetes to properly manage pod lifecycle without unnecessary restarts during temporary dependency issues.
Output: HealthHandler with Health() and Ready() methods, registered at /health and /ready routes.
</objective>
